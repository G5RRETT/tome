# Tome

A personal home for skill files, documents, and scripts.

- `skills/` — skill definitions and their supporting files. Give each skill its own folder with a `SKILL.md` file.
- `documents/` — notes, guides, references, and other documents.
- `scripts/` — reusable scripts and small utilities. Include usage instructions in each script or an accompanying README.

Keep related resources together and use descriptive file names. Keep credentials and secrets out of the repository.
